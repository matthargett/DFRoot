The observed envelope is `[0x80000, 0x17e4c0)`. The provider's configured
envelope rounds the end outward to `0x180000`, yielding four `0x40000`-page
segments. A readable mismatch is fatal. The enforcing `untrusted_app` domain
gets `EACCES` for `/proc/zoneinfo`, so the app reports `descriptor_only`; the
generated shell launcher must rederive and match the unaligned envelope before
it runs the provider.

## Execution-domain result

The provider's dry probe passed inside the enforcing app domain, but a live app
attempt stopped before kernel writes:

- `/proc/zoneinfo` and the filemap tracepoint were unavailable.
- `security.perf_harden` could not be lowered from `untrusted_app`.
- `perf_event_paranoid` remained `3` and `perf_event_open` returned `EACCES`.
- Without a KASLR leak, the provider exited and the adapter did not retry.

The target therefore declares `execution_domain=shell`. Its generated launcher
rechecked identity, hash, PFN range, and all four dry markers. The first guarded
shell-domain attempt then reported:

```text
ROOT VERDICT root=1 uid=2000->0 selinux_permissive=1 (1->0) persist=1(adbd)
```

A fresh ADB connection independently reported UID/GID 0 in `u:r:shell:s0`,
SELinux permissive, full capability masks on `adbd`, and seccomp disabled.
Root remains in-memory and depends on the provider's holder process.

## Kernel and profiling state

The running kernel has `CONFIG_MODULES=y`, `CONFIG_MODULE_UNLOAD=y`, and
`CONFIG_MODVERSIONS=y`. `CONFIG_MODULE_SIG` and `CONFIG_MODULE_SIG_FORCE` are
unset, and `kernel.modules_disabled=0`; an exact symbol-CRC-compatible module
is still required before runtime loading is proven. KPTI
(`CONFIG_UNMAP_KERNEL_AT_EL0`) and read-only kernel text
(`CONFIG_DEBUG_RODATA`) are enabled.

Live profiling verification produced CPU cycles, instructions, L1 data-cache
access/refill, branch prediction, and branch-mispredict counts. The graphics
stack identified Adreno 540 v2 and Qualcomm GLES/Vulkan driver build
`feb9270` dated `2021-06-03`. An unchanged UID 0 `gpuprofserver` in its stock
SELinux domain exposed live KGSL counters. Detailed Vulkan traces showed direct
rendering and hardware binning with four 256 by 256 bins and separate Binning,
Render, and StoreColor stages. No shipped counter is explicitly named tile
spillover, so those traces do not establish a spill count.

`debug.egl.profiler` maps to `qcom_pil_prop`; UID 0 in the shell domain was
rejected by property service. With kernel SELinux permissive, an
`u:r:init:s0`-labeled `setprop` process set it successfully. This userspace
property-service distinction is separate from kernel SELinux enforcement.
